# 🍲 NutriPurna – The Recipe Generator

**NutriPurna** is an **AI-driven web application** nutrition tracking, recipe generation, disease-specific diets, and interactive meal planning features based on each user's health profile and preferences.
NutriPurna is a comprehensive platform designed to simplify personalized nutrition and meal planning, addressing the challenges individuals face with meal preparation, ingredient selection, and dietary restrictions. With health and wellness becoming top priorities, NutriPurna aims to provide customized meal plans, real-time nutrient tracking, ingredient substitution suggestions, and disease-specific dietary recommendations. NutriPurna empowers users to make informed dietary choices, promoting healthier lifestyles while making healthy eating more accessible and manageable. By integrating advanced technology, NutriPurna has the potential to transform how individuals approach nutrition, ensuring they meet their health goals efficiently.



## 🌟 Why NutriPurna?

In India, lifestyle-related diseases such as diabetes, hypertension, obesity, and malnutrition are rising at alarming rates, particularly in middle-income groups where access to professional dietary consultation is limited or unaffordable. NutriPurna fills this critical gap by offering:

✅ Affordable and accessible dietary planning.

🍛 Meals rooted in regional Indian food traditions.

💬 Support for individuals with chronic conditions and daily health goals.

## 🧠 Key Features

### ✅ Personalized Nutrition & Diet Planning
- Health-based onboarding (age, weight, medical conditions, preferences)
- Auto-generated **7-day full-day meal plans**
- Smart recommendations based on user profiles and clinical guidelines

### 🍽️ AI-Powered Recipe Generator
- Generate Indian recipes with step-by-step instructions
- Filter by meal type, calories, nutrients, and available ingredients

### 📊 Nutrient & Wellness Tracker
- Monitor daily intake (calories, protein, carbs, fats)
- Visual insights with charts and health summaries

### 💬 Interactive Chatbot Assistant
- Ask health or food-related questions
- Get instant responses and tips via **NLP-powered chatbot**

### 📚 Disease-Based Diet Library (A–Z)
- Search for health conditions and receive medically aligned food recommendations
- Learn what to eat and avoid for conditions like diabetes, PCOS, hypertension, etc.

## Installation Instructions

1. Download the project as a ZIP file.
2. Extract the ZIP file to your desired directory.
3. Open the project folder in VS Code.
4. Install the necessary dependencies:
   - Open the terminal in VS Code and run:  
     `pip install -r requirements.txt`
5. Run the application:
   - In the terminal, run the following command to start the project:  
     `python sh.py`
6. Enjoy the application!
