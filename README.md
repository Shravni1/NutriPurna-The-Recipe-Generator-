# NutriPurna-The-Recipe-Generator-
This project is an AI-driven web application that provides tailored nutrition advice, recipe generation, disease-specific diets, and interactive meal planning features based on each user's health profile and preferences.
NutriPurna is an innovative AI-powered web platform built to empower individuals with personalized nutrition and wellness solutions, focusing on the dietary habits and challenges faced by the middle-class Indian population. By blending advanced machine learning algorithms with a deep understanding of Indian cuisine, NutriPurna delivers tailored meal recommendations, health-centric recipes, and smart dietary insights designed to improve quality of life through informed eating.

🌟 Why NutriPurna?
In India, lifestyle-related diseases such as diabetes, hypertension, obesity, and malnutrition are rising at alarming rates, particularly in middle-income groups where access to professional dietary consultation is limited or unaffordable. NutriPurna fills this critical gap by offering:

✅ Affordable and accessible dietary planning.

🍛 Meals rooted in regional Indian food traditions.

💬 Support for individuals with chronic conditions and daily health goals.

🧠 Key Features 

✅ Personalized Nutrition & Diet Planning :

User onboarding includes health profile setup (age, weight, medical conditions, goals)

Auto-generates 7-day full-day meal plans based on user preferences, allergies, and restrictions

Smart recommendations based on disease conditions and nutrition science

🍽️ AI-Based Recipe Generation :

Generate recipes with step-by-step instructions

Filter by meal type, calories, nutrients, and ingredients on hand

📊 Nutrient & Wellness Tracking :

Track daily intake of calories, proteins, carbs, fats, etc.

Visual progress charts and health insights

💬 Interactive Chatbot Assistant :

Ask food or health-related queries

Get instant diet suggestions, disease info, or tips using NLP-based conversation

📚 A–Z Disease-Based Diet Library :

Search for health conditions and receive medically aligned food recommendations

Learn what to eat and avoid for conditions like diabetes, PCOS, hypertension, etc.
